# ケロちゃん ぴよぴよポン

たまごを とばして、おなじ いろを 3つ くっつけると ひよこが うまれる ゲームです（5〜6歳向け）。
「Egg Shooter Dynomite」のようなたまごシューターを、「ケロちゃん もぐもぐ」と同じキャラクター・雰囲気で作りました。
ブラウザで動き、Android の Chrome から「アプリとしてインストール」できます（PWA）。

- 5ワールド × 12ステージ = 60ステージ ＋ エンドレス（おまけモード）
  - ステージ：ならんだ たまごを ぜんぶ われたら クリア。つかった たまごが少ないほど ★が多い
  - エンドレス：上から どんどん たまごが出てきます。うまれた ひよこの数が記録になります
- たまごは時間とともに下がってきます。点線まで来ると警報が鳴り、3びょう以内に消せないと「ざんねん」
- はやさはタイトル画面で えらべます：ゆっくり（1段 30びょう）／ふつう（16びょう）／はやい（9びょう）。★の基準はどのはやさでも同じ
- とくべつな たまご：ばくだん（まわりを ドカン）、にじいろ（くっついた色に へんしん）、かみなり（よこ一列を ピカッ）、いし（色では消えない。まわりを消して落とす）
- 画像・音のファイルは使わず、すべてプログラムで描画・合成しています

## あそびかた

- 画面をさわって ねらい、はなすと たまごが とびます（点線と うすい たまごで、どこに くっつくか分かります）
- かべに当てると はねかえります
- ケロちゃんが だっこしている たまご（つぎの たまご）をタッチすると、入れかえられます
- 上の たまごが われると、ぶらさがっている たまごも おちて ひよこが うまれます

## PC で試す

```
python -m http.server 8766 --directory .
```

ブラウザで http://localhost:8766 を開きます。

## Android にインストール

1. GitHub Pages などで公開した URL を Android の Chrome で開く
2. メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
3. 一度開けば、オフラインでも遊べます

## おみせ（キャラクター）

- ステージで集めた★で、おともだちを買えます：ミミちゃん（うさぎ）★10・ニャーちゃん（ねこ）★20・ワンちゃん（いぬ）★30
- 買ったキャラクターは「えらぶ」で切り替えられ、発射台の となりで たまごを だっこします
- ★や買ったキャラクターは「ケロちゃん もぐもぐ」とは別です

## おうちの方へ

- タイトル画面左上の家のボタンで、ゲームのメニュー「ケロちゃん ランド」（https://manhtuan87.github.io/）に もどれます

- タイトル画面左上の ⚙ ボタン → 管理者パスワード（123）で、管理者メニューが開きます
  - 全ステージ解放（すべてのワールド・ステージを選べるようにする）
  - 記録をリセット（★・買ったキャラクター・エンドレスの記録も最初に戻ります）
- 💡ボタンで、いちばん良い ねらい先を 手のマークで教えてくれます（入れかえた方が良いときは、だっこしている たまごを指します）
- はじめて遊ぶ しかけのステージでは、ケロちゃんの ふきだしで説明が出ます

## 開発メモ

- `js/engine.js` … たまごの並び・発射・3つそろい・落下・警報などのルール（Node.js のツールと共通）
- `js/levels.js` … ステージ（`tools/make-levels.js` が生成。直接は編集しない）
- `node tools/make-levels.js` … 形（ハート・アーチなど）と色の並べ方からステージを作り、ためしプレイで難しさをそろえます
  - `node tools/make-levels.js build 4-10` で1ステージだけ作り直し、`node tools/make-levels.js write` で `js/levels.js` を書き出し
- `node tools/verify.js` … 全ステージの形のチェックと、ためしプレイ（ゆっくり＝小さい子モデル、ふつう・はやい＝子どもモデル）
- `tools/bot.js` … ためしプレイ用のプレイヤー（expert / kid / little）
- アイコンは `tools/icon.html` をゲームの絵で描き、`tools/make-icons.ps1`（ヘッドレス Chrome）で PNG にしています
- 更新を配信するときは `sw.js` の `VERSION` を上げてください（次回起動時に新しい版に切り替わります）
- 同じサイトに「ケロちゃん もぐもぐ」がある場合もキャッシュが混ざらないよう、この `sw.js` は `piyo-` で始まるキャッシュだけを消します
